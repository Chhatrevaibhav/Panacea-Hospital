### Introduction

A modern and responsive admin dashboard designed for managing your applications. Built with React and Tailwind CSS, featuring multiple pages and components for various use cases.

### Features

- Modern UI with Tailwind CSS
- Responsive design
- Authentication system
- User management
- Dashboard analytics
- Patient management
- Appointment scheduling
- Lead tracking
- Call management
- Reports and analytics

### Quick Start

Install the project dependencies:

- Install NodeJS LTS from [NodeJs Official Page](https://nodejs.org/en/) (NOTE: Product only works with LTS version).

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

Start the backend server (in a separate terminal):

```bash
cd backend
npm install
npm start
```

### Project Structure

- `/src` - Frontend React application
- `/backend` - Backend Node.js server
- `/public` - Public assets
